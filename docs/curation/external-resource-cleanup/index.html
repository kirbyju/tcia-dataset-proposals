Proposal for review. No WordPress edits have been applied. The worklist recommends replacements using existing labels. The resource-link/content checks below remain part of the curator's work.

34 registered labels → 6 proposed broad categories · 47 legacy assignments across 34 datasets · 7 options with no visible public use

Scope: the WordPress external_resources field and its /api/v2/supporting-data registry. The normalized query API also calls the array external_resource_labels. This is separate from download category, data type, and file type.

Use these six existing labels

Keep the detailed organ, method, assay, format, and measurement wording in each resource's title or description. Multiple categories are appropriate only when the linked resources support each one.

Proposed labelMeaning for this cleanup
ClinicalPatient characteristics, diagnoses, treatment, outcomes, and clinically reported measurements.
GenomicsDNA/RNA molecular information, gene expression, genomic subtypes, and gene-based assays. Keep the assay name in the resource description.
HistopathologyMicroscopic tissue images and associated histopathologic information.
Image AnalysesImage-derived annotations, segmentations, measurements, features, registrations, quality assessments, and derived analysis images.
ProteomicsProtein abundance, protein assays, and protein-derived analysis features.
Software/Source CodeSoftware, scripts, source code, and executable analysis tools; this label alone does not imply analysis data are provided.

Instructions for curators

  1. Use the six existing broad categories below as the recommended targets. This cleanup needs no new WordPress label values; resolve the content-dependent choices before replacing those assignments.
  2. For each affected dataset, open its current WordPress record and follow the relevant supporting-resource link. Confirm what the destination actually provides; a paper describing data does not prove those data are available there.
  3. Change only the external-resource label assignment. Preserve every resource URL, resource title, citation, access requirement, and useful description. Keep separate links even when several receive the same broad label.
  4. Use the crosswalk for ordinary image-analysis aliases. Resolve each content-dependent row explicitly; do not automatically assign every proposed label in those rows.
  5. Within a dataset filter list, deduplicate repeated broad labels after replacements. Do not globally rename an old option into a duplicate of an existing option. Multiple resource entries with different URLs may still share a label.
  6. Do not change download category, data type, file format, species, disease labels, or dataset/source relationships as part of this pass. These dimensions have their own rules.
  7. After replacing all assignments, check the full WordPress admin for remaining references, including hidden/unpublished records. Public zero-use counts do not establish that the option is unused everywhere.
  8. Retire obsolete options only after that complete reference check. For no external resource, leave the field empty; do not use NA, Not Applicable, None, or Other placeholders.
  9. Refresh the registry and public metadata export, confirm all intended links remain, inspect representative edited pages, and compare expected and actual distinct dataset counts for the retained labels.

Evidence and limits

  • Public metadata and dataset narratives were reviewed. Supporting-resource destinations/payloads were not systematically opened or downloaded; curator link/content verification remains required.
  • Counts are exact-label distinct visible datasets and overlap across labels. Collections and Analysis Results remain separate records.
  • This is a classification cleanup. A linked resource may be on TCIA or elsewhere; the label does not establish hosting location, access authorization, or patient-level availability.
