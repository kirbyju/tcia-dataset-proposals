## Specific concept candidates

Existing **Healthy Subject** has the NCIt candidate **C49651**, supported by the [NCI EVS published terminology](https://evs.nci.nih.gov/ftp1/CDISC/Glossary/CDISC%20Glossary.html). **Desmoid-Type Fibromatosis** has candidate **C9182**, supported by [NCI EVS mappings](https://evs.nci.nih.gov/ftp1/NCI_Thesaurus/Neoplasm/Archive/Neoplasm_Core_Mappings_NCIm_Terms_2016-06-15.html). The current EVS API also verified **Healthy Subject, C49651**, active in NCIt **26.09d**, on October 16. Its NCI definition requires no significant health-related issues. Current API verification of C9182 remains pending; the archived mapping alone does not establish current activity or approve a new WordPress value. Trigeminal Neuralgia and tubal precursor lesion concepts still need terminology review.
