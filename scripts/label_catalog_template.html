Using the terminology and examples

Recordsets describe downloadable groups of files and correspond to TCIA download records. A recordset has one data category, one or more data types, and one file type. Use separate recordsets when the category or file type differs. The table below shows examples; these are not restrictions on valid combinations.

DICOM abbreviations are explained using DICOM Modality Defined Terms. SC means Secondary Capture, a TCIA object label rather than a current modality defined term.

Definition sources and NCI standards

DICOM defines imaging modality codes and derived objects such as segmentations and structured reports. Follow the DICOM definition beside a type to read its standard meaning. A type label alone does not establish the file format; CT images, for example, can be supplied as DICOM or NIfTI.

caDSR registers Common Data Elements: field meanings, representations, and permissible values. NCI Thesaurus (NCIt) supplies terminology concepts and definitions used to annotate those elements. A caDSR field reference and a term definition serve different purposes.

TCIA categories and non-DICOM types describe the role and contents of a data component. Alignment with a caDSR element requires review of its definition and value domain, including version and scope. These labels do not imply an exact caDSR or NCIt mapping. The proposal category/type relationships above remain TCIA selection guidance.

Disease and primary disease site

Disease labels describe diagnoses or cohort context. Primary disease sites describe where the disease originated; scanned anatomy, metastatic sites, and annotation targets can differ. Where available, concept links point to NCI Thesaurus (NCIt) disease definitions and UBERON anatomy definitions.

Non-Cancer is a broad discovery label and can accompany a specific nonmalignant disease or Healthy Subject label when supported. Absence of cancer does not by itself establish healthy status. Phantoms belong under species or subject type; retain applicable simulated disease context and use Not Applicable when disease or site does not apply.

Data types and formats

A category describes the broad role of the data; a type describes the information or imaging object; a format describes how it is stored. For example, a DICOM segmentation can be Image Annotations / SEG / DICOM. A NIfTI labelmap can be Image Annotations / Segmentation / NIfTI.

Describe the files inside an archive using their content format. Packaging and transfer manifests can be recorded separately. External resources are links to related material and do not establish a TCIA-hosted download.

Terms and published examples

Available terms and published use are distinct from suitability for a particular dataset. Examples illustrate how labels have been used; a terminology link does not confirm that a concept applies to every dataset. TCIA reviews proposed labels during curation.
